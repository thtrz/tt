## 先把问题讲清楚
我的第一个实践项目，是电商商品图片提取插件。目标是把详情页里的图片集中起来，先挑选，再下载，减少逐张保存的重复操作。

需求拆成四部分后，就更容易理解：
1. 商品页面上需要一个明确的入口。
2. 扫描页面里可取得的图片地址。
3. 在独立页面中预览、筛选和勾选。
4. 将选择的图片转换为 PNG，再保存到本地。

## 让第一个版本跑起来
项目采用浏览器扩展技术，不需要通过 AI 接口处理图片。AI 帮助编写代码，实际运行时则由浏览器扫描、转换和下载。

~~~javascript
// 先明确数据结构，再把功能连接起来。
const image = {
  url: 'https://example.com/product.jpg',
  width: 800,
  height: 800
};
~~~

## 人工测试很重要
我在 Edge 中加载了插件，并在淘宝商品页看到了提取出的图片。预览结果里也出现了淘宝标志和店铺图标，这提醒我：自动提取之后，仍然需要尺寸筛选和人工选择。

**目前确认完成的是提取与预览。** PNG 下载及其他平台兼容性需要继续用实际结果验证，不能只看代码就认定全部完成。
