## 上传代码，还没有完成发布
把项目文件上传到 GitHub 后，仓库页面可以看到文件和提交记录。这个地址适合查看代码，但还不等于用户访问产品的页面。

## 三种地址分别做什么
- 仓库网页：例如 https://github.com/thtrz/imagegrab ，用于查看代码和提交记录。
- 克隆地址：以 .git 结尾，供 Git 工具复制项目。
- 网站地址：例如 https://thtrz.github.io/imagegrab/ ，用于访问部署后的页面。

## 选择正确的发布目录
不同项目的首页位置可能不同。图片插件的官网放在 docs 文件夹里；这个个人网站的首页放在仓库根目录。

~~~text
个人网站的分支发布配置：
Source: Deploy from a branch
Branch: main
Folder: / (root)
~~~

## 截图要能证明结果
展示部署结果时，应该同时截到浏览器地址栏与实际网站页面。只截仓库文件、设置页面或本地 file 地址，不能证明公网网站已经打开。

## 遇到 404 时
先检查 Pages 是否开启、分支和目录是否正确、首页文件名是否为 index.html，再查看部署任务有没有完成。
